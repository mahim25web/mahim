# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript. Designed to showcase my profile, projects, and web development skills.

🚀 **Live Demo:** [mahim-dev.vercel.app](https://mahim-dev.vercel.app)

---

## 🌟 Features

- **Responsive Design:** Optimized for all screen sizes, from mobile devices to desktop displays.
- **Interactive Elements:** Smooth navigation and interactive features powered by lightweight JavaScript.
- **Clean UI/UX:** Styled using custom CSS with optimized media assets for fast load times.

---

## 🛠️ Built With

- **HTML5:** Semantic layout and structure.
- **CSS3:** Custom styles, layouts, and animations.
- **JavaScript (ES6+):** Dynamic behavior and client-side logic.
- **Vercel:** Continuous integration and live hosting.
